# OOP-Practical-3: Constructors and Rule of Five

## Purpose & Aim
- **Aim**: To understand object creation, copying, moving, and safe management of an owned resource.
- **Question**: Implement a class that demonstrates default, parameterized, copy and move constructors, and the Rule of Five.

---

## What to Do
- Create a small resource-owning class, for example a class that manages a dynamically allocated integer array.
- Implement a default constructor and a parameterized constructor.
- Implement a copy constructor and copy assignment operator that perform a deep copy.
- Implement a move constructor and move assignment operator that transfer ownership safely.
- Implement a destructor to release the owned resource and add comments explaining all five Rule of Five members.
- Create objects that exercise each constructor/assignment path.
